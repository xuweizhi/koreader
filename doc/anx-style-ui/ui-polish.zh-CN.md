# W47：常用操作优化

本轮落实界面评审中优先的三条流程：模型管理、聊天输入和电子书导入。继续使用 KOReader Lua 组件与原阅读引擎。

## 操作变化

- **AI → 模型**直接进入模型配置列表，提供可见的编辑按钮，以及 DeepSeek / 自定义配置入口。
- 聊天页直接输入和发送；“新对话”与“停止”分开，重试只在适用状态出现。切换模型、界面刷新、旋转及关闭后再次进入时保留未发送内容。返回键先收起键盘，再次返回关闭聊天。
- 手动导入使用明确的勾选状态，底部显示导入数量和确认按钮；目录选择提供“扫描此文件夹”。支持当前目录全选和清空选择。
- 书架常用控件的触摸区域提高到 48dp；新增界面沿用 Anx 的颜色、圆角与文字层级。

模型协议、书籍读取、扫描去重和文件存储语义沿用现有实现。继续阅读卡片、书架批量管理与扫描目录管理已由 [W48](bookshelf-polish.zh-CN.md) 实现；参考内容与阅读任务分组见 [W49](reading-ux.zh-CN.md)，全局适配与最新交付见 [W50](global-polish.zh-CN.md)。

未发送草稿写入 AI 私有目录下的 `draft.json`，按书籍与通用聊天分开保存，最多 8 份、每份 32 KiB；成功发送后清除对应草稿。超过保存上限时显示提示并保留当前输入框原文。剪贴板与选区弹窗在旋转、关闭聊天时一并关闭。

## 验证与交付

- **安装包**：[ARM64 anxui8](/data/koreader-anx-work/artifacts/android-ui-01/koreader-anx-arm64-development.apk)，版本码 `122542`，沿用开发签名，可覆盖旧开发版；内置插件，无需另装 ZIP。
- **本地回归**：17 组、144 个单元用例通过，38 个 Lua 文件静态检查通过。真实 SDL 验证窄屏、横屏、大字、8 配置分页、输入草稿、流式错误/停止/历史，以及导入勾选、全选/清空、选中后横竖屏切换、目录扫描去重和重启。
- **Android**：API30 / Android 11 x86_64 专用模拟器，最终 `w47-ui-04` 通过实际触摸发送、中文剪贴板输入、草稿退出恢复、剪贴板弹窗随旋转关闭、键盘横竖屏、停止、返回、前后台和重启记录恢复。保留已有私有配置和历史，未清除应用数据。
- **异常记录**：模拟器在旧版启动时出现 System UI 无响应；后续 anxui8 启动器更新资源期间又出现原生焦点事件超时，时间早于 AI 测试初始化。记录并处理弹窗后重跑交互通过，不能据此宣称升级启动 ANR 已修复。首次内嵌键盘发送未转发事件的问题已修复；另有一次测试脚本连续读取剪贴板的断言失败，调整为使用首次已验证的读取值。
- **边界**：本轮未重测真实模型协议；未完成 ARM64 真机或墨水屏测试。模拟器结果不代表真机性能、系统中文输入法或所有升级情形。

完整证据见 [W47 验证汇总](/data/koreader-anx-work/evidence/W47-ui-polish/summary.json)，旧批次的结果仍按原源码版本解释。APK 及源码未包含服务凭据。
