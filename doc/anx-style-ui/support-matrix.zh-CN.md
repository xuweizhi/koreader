## 已知失败、限制与证据时效

当前仍保留原 `kodev check` 两处 ShellCheck 失败，以及历史在线翻译的 HTTP 429 / wantread。OCR 测试模型、版本标签元数据和 gettext 告警已修复环境或新增代码并复验，统一在 [本地回归记录](local-regression.zh-CN.md) 跟踪；不能将本地通过写成所有联网检查通过。OCR 单元回归也不能代替 W24 扫描文档的完整 OCR 集成验收。

历史失败原始证据保留：W24 脚本扩展名白名单、W29 在错误上下文寻找 OPDS、W30 图标焦点/几何检查脚本假设等已纠正，并有新结果；不把这些测试工具修正描述为新增引擎能力。W33 发现的 composer 重建归属缺口已有产品修复和真实无网络复测。

只有实际复测过的改动才获得新证据。W33 已归并 AI 生命周期、设置路由和内存优化，并补验当前书架、视觉与恢复；旧证据仍保留原源码快照。最终包、Linux 本地候选、Android 模拟器、Android 实机及墨水屏支持分别签收，不相互替代。
