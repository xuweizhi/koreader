# Anx 风格 KOReader

在 KOReader 中提供卡片书架、图文导航、笔记、统计与设置页面。阅读引擎、文档格式、批注锚点和原插件仍由 KOReader 负责。当前交付是独立的 `anxui.koplugin`；无需修改核心源码。

这是 Anx 风格的 Lua 界面实现。排版、高级设置、词典、同步和导出等功能继续使用 KOReader 原窗口。它没有移植 Anx 的 Flutter 运行时，也没有替换原书籍数据库。

## 使用

Android 候选 APK 已内置插件，安装后直接从第 2 步进入。下述手工复制用于能够访问安装目录的 KOReader；Android 开发包的签名和验证范围见文末说明。

1. 退出 KOReader，将插件包中的 `plugins/anxui.koplugin` 放到对应安装的 `plugins` 目录。只复制插件目录，不覆盖全局设置或书籍文件。
2. 启动后，打开原主菜单，点击第一个分页或“工具”分页顶部加粗的“打开 Anx 书架”。经典书架和阅读界面都提供这个入口；“更多工具 → Anx 书架”仍可使用。默认保留原启动方式；需要时在“Anx 外观”中启用启动书架。
3. 书架默认显示已导入的全部书籍。点击右上角“＋”，选择“导入电子书”多选文件，或“扫描电子书文件夹”递归添加目录中的书。进入目标目录后点击左上角 ✓ 确认；扫描可取消，重复路径自动跳过。“重新扫描已保存的文件夹”用于收录新增文件。
4. 顶部可搜索、筛选已读完/正在读/未开始；右上角菜单提供排序、网格/列表、继续阅读和同步。手机书架上下或左右滑动翻页；键盘 PageUp/PageDown 也可使用，宽屏另有翻页箭头。文件夹图标可切换当前目录、最近阅读、收藏和书单。长按书籍打开原信息、收藏、移动或重命名窗口，也可只从书架移除。
5. 底部导航或宽屏侧栏提供书架、统计、AI、笔记、设置。跨书笔记需先重建索引，索引可随时取消、清空和重建。
6. 阅读时从原菜单打开“Anx 阅读工具”，进入目录、进度、当前书笔记及常用原生动作。原阅读手势、选字菜单与高级设置仍可使用。
7. 书架右上角菜单中的“经典界面”或系统返回键回到原文件管理器；再次打开原主菜单，点击“打开 Anx 书架”即可回来。原插件管理器可禁用 Anx；重启后恢复经典流程。

支持彩色、灰度与大字选项。界面文案提供中文和英文，其他语言使用英文回退。灰度模拟结果不表示已完成墨水屏硬件验证。

上述置顶入口从 W40 的 `anxui2` 更新开始提供，旧 `android-candidate-02` 包仍使用“更多工具”入口。更新方式、截图和本次验证范围见[入口更新记录](entry-update.zh-CN.md)。

书架布局、多选导入与目录扫描从 W41 的 `anxui3` 更新开始提供，见[书架更新记录](bookshelf-update.zh-CN.md)。此前安装包保留原样；新版 APK 已内置插件，无需另装 ZIP。

## 数据与可选功能

阅读位置、笔记、历史、收藏、统计均复用原模块。Anx 自己保存外观选项和可删除的跨书笔记索引；详细位置及异常恢复步骤见[恢复说明](recovery.zh-CN.md)。

导入保留电子书原位置，不复制书籍或批注。书架成员保存在原 `collection.lua` 的专属 Anx 书单中，扫描目录作为该书单的设置保存；重启后仍可使用。从书架移除不删除文件。通过 KOReader 原窗口移动、重命名或删除文件时沿用原书单更新机制；在其他应用中移动文件后需重新导入。重复判断按规范化后的文件路径，不会把不同目录的同名书合并。扫描跳过隐藏项、`.sdr` 附属目录、独立图片与符号链接，最多递归 32 层。

统计概览读取原统计插件已写入的区间，当前尚未结束的页面计时由原插件管理。封面依赖原 coverbrowser 缓存；能力缺失或插件被禁用时显示对应状态。

AI 入口桥接单独安装的 KOAssistant。仅支持[已审计的固定提交](koassistant-audit.zh-CN.md)，不会自动安装、下载或发送书籍内容。密钥、配置与对话由原插件管理；服务实测状态单列，配置存在不能当作模型请求成功。

## 版本与验证

兼容核心固定为 `dcb50ae439f2acd82aec213063e76739984eacb1`。其他 KOReader 版本需重新验证原菜单 ID、插件接口与数据结构。每个成果包附文件 SHA-256 和核心/子模块身份。

当前结果查阅[支持与待测矩阵](support-matrix.zh-CN.md)、[唯一执行记录](execution-state.json)、[视觉检查](visual-review.zh-CN.md)和[37 插件检查](plugin-matrix.zh-CN.md)。源码、签名 APK、Linux 本地结果、Android 模拟器结果和实机结果分别列出。

Android 开发包使用本地测试证书，包名仍是 `org.koreader.launcher`。签名与现有 KOReader 不同时不能直接覆盖安装；测试包先用于独立模拟器。不要为安装测试包删除个人设备上的阅读数据。

## 开发与复测

在固定核心仓库中，插件目录位于 `plugins/anxui.koplugin`，单元测试位于 `spec/unit/anxui_*_spec.lua`，真实 SDL 场景和平台工具位于本目录的 `tools/`。所有运行工具要求独立的运行与证据目录，拒绝覆盖已有结果。

```sh
env PARALLEL_JOBS=1 ./kodev test -b -j 1 front 'anxui_*'
./kodev check
```

`-b` 使用已构建的本地运行时，首次使用前需按 KOReader 构建说明准备原生库与测试数据。完整前端测试应串行运行；原测试工具每次会重新创建共享的 `spec/run`。最终回归记录区分新增失败、原版失败和外部服务失败。

打包工具 `tools/package-candidate.py` 仅生成本地成果，不执行安装、推送或发布。Android 构建使用 `./kodev release -i android-arm64`，`-i` 保留固定翻译子模块版本。来源与许可见[来源清单](sources-and-licenses.zh-CN.md)。
