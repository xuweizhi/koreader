# Lua UI 视觉规格 v1

这是 W05 的目标规格，页面是否已实现和实测仍以 execution-state.json 为准。参考版本：Anx `0c7fc1ad4551f7dbbeba6a6468f69d830957fa2a`。已查看其 `docs/images/zh/mobile1.png`、`wide1.png`、`mobile2.png`、`mobile3.png`，并核对 `lib/page/home_page.dart`、`home_page/bookshelf_page.dart`、`home_page/notes_page.dart`。宣传图有设备外框，不能作为像素差分基准。没有复制品牌图标或书籍封面资源。

## 共用规则

所有尺寸是 KOReader 的逻辑单位，布局使用 `Screen:scaleBySize`，字体交给 `Font:getFace` 的原缩放机制，禁止重复缩放字体。页面不更改全局 Size、字体映射、原 Menu 或阅读布局。

| 项目 | 彩屏 | 灰度/墨水屏 |
| --- | --- | --- |
| 页面底色 | `#FAFBFE` | 白 |
| 卡片/导航 | `#EEF2FA` | `#EEEEEE`，必要时加黑边 |
| 强调底色 | `#D7E6FA` | `#D0D0D0`，同时有文字选中标记 |
| 文字 | `#182636`，次要 `#556477` | 黑，次要 `#555555` |
| 强调色 | `#315F8B` | 黑 |
| 分隔线 | `#D7DFEB` | `#999999` |
| 圆角 | 卡片 12，控件 12，底部导航 28 | 卡片/控件 4，导航 8 |
| 动画/模糊 | 首版不启用；用静态实色表面表达层级 | 不启用 |

间距：4/8/12/16/24。点击高度取 `max(scaleBySize(48), scaleByDPI(44))`；实测 360 窗口下原按屏幕缩放会将 48 缩至 29 像素，因此增加 DPI 下限。图标本体 20–24，外层使用上述点击区。标题 28、分组标题 20、正文 18、次要文字 14。使用 KOReader 内置 Noto Sans/CJK 后备字体。正常/大字模式倍率 1/1.25，不缩小到难读字号来塞下长标题；标题最多两行，详情提供完整文本。焦点必须有轮廓/反色，不能仅靠淡色变化。

选中、可用、禁用、加载、空、错误六种状态必须可区分。未知作者/进度显示“作者未知”/“未读”，不能杜撰。缺功能入口显示原因及原界面入口，不能伪装已接通。新字符串提供简体中文与英文，其他语言回退到 KOReader 翻译或英文。

## 01 竖屏书架（目标页）

基准 540×720、DPI 160；另验 360×640。逻辑宽度小于 720 使用底部导航。

- 外边距 16，顶部标题/关闭区 48；搜索区 48；全部/最近/收藏筛选区 48。窄屏优先搜索和筛选可达，次要动作收进更多。
- 网格按剩余宽度和文字倍率计算列数，至少 1 列；封面保持原比例，卡片标题两行、作者一行、进度一行。封面缺失用明确的书名占位，不能用随机封面冒充真实内容。
- 列表模式每行至少 88，左侧封面、右侧书名/作者/进度。每页只创建可见行，底部上一页/下一页点击区各 48，页码和结果数可读。
- 底部导航高 64，左右与底部留 16，圆角 28；书架、笔记、统计、设置为目标顺序。未实现页不显示可点击空壳。AI 入口仅在已验证能力允许时出现。
- 当前实现初期只有当前目录书籍和回经典界面，其他导航随对应批次接通。不能把该过渡态声称为全部/最近/收藏书架完成。
- 空态在内容区显示原因和“打开文件浏览器”；搜索无结果可清空搜索；文件消失显示刷新/原目录动作。

## 02 宽屏书架（目标页）

基准 1280×800、DPI 160；720 逻辑单位为侧栏切换阈值。Anx 源码使用 600，本项目沿原方案 720 起点，为 KOReader 字号和操作区留空间；后续若修改阈值须保存对应截图。

- 左侧导航宽 96，外边距 16、圆角 20；图标与文字并存。正文占剩余宽度，搜索不超过 480，右侧常用动作和经典界面入口保持可见。
- 网格每格宽度按 140–180 逻辑单位分配；不把少量书籍拉伸成巨大封面。列表最大文本区宽度 900，并保留页面左右留白。
- 页面尺寸变化保留当前源、查询、排序、页码和选中书。重排时旧组件、任务和封面释放；不再创建 ReaderUI。
- 键盘顺序：页头 → 搜索/筛选 → 书籍 → 分页 → 导航。Esc/返回关闭当前弹层，回到原 FileManager。

## 03 阅读工具栏（目标页，W19 实现）

基准 540×720 与 1280×800。正文仍由原 ReaderUI 绘制，工具栏按需显示，关闭后不占正文空间。使用原菜单入口或独立明确动作召唤，不截获所有翻页/选字手势。

- 顶部区域高 56：书架、当前书名（省略长标题）、关闭/更多。底部卡片内边距 16、圆角 16，宽度随屏幕，宽屏最大 720。
- 目录、进度、排版、笔记、搜索、原高级菜单为基础动作；按文档能力显示或解释不可用。PDF 的原裁边、重排、OCR 通过高级菜单保持可达。
- 按钮至少 48，两行布局容纳长中文，不压缩字号；页码/百分比显示原模块值。
- 打开原窗口前关闭/隐藏本工具栏，返回保持同一本书和位置。选字窗口、键盘、系统返回和原按键不得被不可见覆盖层截断。
- 无活动文档、已关闭会话、插件禁用分别有状态；不调用旧 ReaderUI。

## 04 笔记列表（目标页，W21/W23 实现）

基准 540×720 与 1280×800。页头 56，书籍摘要卡片内边距 16；数量 28 加粗、标签/副标题 14。过滤区高 48。

- 笔记卡片圆角 12、间距 8、内边距 12；正文至少 18，元信息 14。摘录最多 4 行，备注另行显示；不能把备注替换为摘录。
- 文本锚点直接来自原批注。类型用图标加文字表示，颜色只辅助；页码/章节/时间缺失时省略，不能推算伪造。
- 点击定位原文；编辑、删除和导出先委托原窗口。长按/更多动作可用键盘到达。
- 宽屏主内容可分书籍列表与笔记详情两栏，但以适配器数据一致性优先，未实现的两栏不能算已完成。
- 无笔记显示原书签/批注入口；跨书索引未建立显示“建立索引”，扫描中可取消；删除缓存不删原笔记。

## 验证容差与证据

固定 DPI/字体/主题下，主要布局边界允许 ±2 物理像素的取整误差；字体因后备与渲染差异不作跨系统逐像素判定。验收必须实际查看页面截图，关注溢出、遮挡、焦点与操作可达。彩屏与模拟灰度分开保存；模拟灰度不能证明墨水屏残影和硬件按键正确。

W05 只验主题在当前页面可见，W06 验组件；四类页面全部实测在 W30/W33。本文件不作为功能通过证据。
