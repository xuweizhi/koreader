# W48：第二批书架与文件管理优化

沿用 KOReader 的文档、阅读状态和原生收藏夹，改进常用书架操作。

## 如何使用

- **继续阅读**：未搜索或筛选的 Anx 书架展示最近打开的书及进度，点击整张卡片继续。文件缺失时隐藏；极短或大字横屏优先保留书目，继续阅读仍在菜单中。
- **全部筛选**：顶部提供“全部、正在读、已读完、未开始”。“全部”清除阅读状态筛选，保留搜索词。
- **书卡更多**：每本书卡片上有可点击的 `⋯`，长按也可打开同一菜单。
- **批量管理**：书架右上角菜单 → 批量管理，或书卡更多 → 选择／批量管理。选中可跨页保留；底部显示数量，提供全选本页、清空选择、批量操作、退出选择。返回键先退出选择。
- **批量操作**：可加入已有分组（原生收藏夹）、标记已读完或移出 Anx 书架。标记已读完保留阅读位置、评级和笔记；移出仅移除 Anx 书架成员，不改变其他收藏夹，也不删除文件。完成后显示成功、未变动或不可用、失败数量。
- **扫描目录管理**：书架右上角 `＋` → 扫描目录管理。查看可用状态和上次扫描时间，点击目录重新扫描或移除记录；添加目录仍复用原扫描确认、进度、取消和去重流程。移除目录记录保留已导入书籍。

目录扫描成功后记录时间；旧版目录列表可直接使用。文件仍留在原位置；移动外部存储或目录后需要重新选取可用路径。

## 验证与安装包

- **安装包**：[ARM64 anxui9](/data/koreader-anx-work/artifacts/android-ui-02/koreader-anx-arm64-development.apk)，版本码 `122552`，沿用开发签名并内置插件。两种 ABI 均已构建、签名，逐文件确认包内插件与当前源码一致；[包信息与校验值](/data/koreader-anx-work/artifacts/android-ui-02/artifacts.json)。
- **本地检查**：18 组、152 个单元用例通过；39 个 Lua 文件静态检查无警告。验证了标记已读保留进度、评级和笔记、移出书架保留原文件和其他收藏夹、写入失败回滚，以及取消确认后的旧回调失效。
- **实际 SDL 交互**：480×800 彩色与 360×640 大字灰度各完成导入、选择后横竖切换、跨页批量、分组、已读筛选、移出、单目录重扫/移除/加回、继续阅读及进程重启，共 54 张截图。最终大字灰度回归的插件源码哈希与交付包一致，额外覆盖多选时返回先退出选择、显式切换经典界面后回到 Anx。
- **Android 未完成**：专用 API30 x86_64 模拟器启动期间两次出现系统进程 `Lost network stack` 致命异常，随后 System UI 报 `DeadSystemException`。第一次预检在新版安装前因窗口服务不可用失败；服务恢复后再次尝试，APK 安装返回非零，尚未进入应用界面。原安装器输出未被旧脚本保留，因此不把具体安装错误归因到 APK 或某个系统服务；后续脚本已补充失败输出采集。本轮不宣称 Android 交互通过，ARM64 真机与墨水屏仍待测。
- **限制**：前一轮的升级启动 ANR 未作为本轮修复项；640×360 大字导入选择器可操作，但每页条目较少，留待全局适配。未调用真实 AI 服务。APK 与插件未包含服务凭据。
