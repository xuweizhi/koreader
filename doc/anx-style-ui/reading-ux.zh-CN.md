# W49：第三批阅读工具与 AI 操作优化

## 阅读工具

“Anx 阅读工具”首先显示目录、进度、笔记、阅读设置、书签和 AI。点击“更多工具”访问搜索、上一位置、高级设置、书架和词典，再点“常用工具”返回。空间不足时分页，按钮仍可通过触摸和方向键访问。返回键或点击面板外关闭工具，继续当前阅读。

## AI 参考内容与阅读任务

- **参考内容**显示当前附上的章节、选文、笔记或检索结果，提供直接预览和移除。添加、更换或移除参考内容保留现有对话及输入草稿。
- **阅读任务**独立提供解释、翻译、总结、阅读报告、思维导图和对照翻译。尚未添加原文时提供添加入口。
- **检索与工具**集中管理书内检索、跨书检索、文字索引及阅读工具开关，保留原来的启用确认和调用次数限制。
- **引用跳转**：新回答保存本次生成的来源。点击回答中的 `[S1]` 等引用或“引用来源”即可回到原文；更换或移除当前参考内容不改变已有回答的来源。完整回答和对照翻译也使用该回答的来源。书籍变化或锚点失效时提示重新选择原文。

更改参考内容只影响后续请求。重试和编辑重发也使用当前参考内容，并重新生成该回合的来源；移除原文后不会通过重试隐式附回旧原文。已有问题和回答仍在聊天记录中，仍作为对话消息发送。

旧版历史回答没有独立来源快照时，会显示未保存来源，避免把旧引用错误指向新附上的内容；仍可查看旧消息和当前会话保存的参考内容。模型生成的外部链接不会变成可执行操作，只有实际保存的本地来源编号可跳转。

键盘打开后会精简顶部操作，短横屏优先保留输入和停止按钮；空间不足时，生成中的“停止”使用发送键的位置。停止或失败后，有草稿时仍可发送新问题，空草稿时提供重试。收起键盘即可恢复完整参考内容和任务入口。旋转保留输入草稿。
