# W50：第四批全局适配与回归

本轮统一书架、导入、设置、笔记、统计和 AI 表单的操作细节。继续使用 KOReader 原阅读引擎、文件和批注数据，新增界面不另建阅读数据来源。

## 操作变化

- **焦点与返回**：书架异步加载、刷新和旋转保留当前按钮或书籍的键盘焦点。设置、目录和笔记列表支持 PageUp/PageDown；设置子页面的返回键回到上一级。刷新列表保留正在操作的项目。
- **小屏和大字**：设置、笔记和统计沿用书架的字号和触摸密度。空间不足时，列表合并工具栏、折叠筛选并缩短页脚，统计卡片分页。极短横屏的书架把筛选和导航收进顶部菜单，保留至少一行书籍；菜单仍可分页访问全部操作。
- **手动导入**：根据实际可用高度安排文件行，避免横屏只显示一行或快捷键框过大。全选、清空和旋转保留当前文件位置、页码和焦点；短横屏将确认区合为一行。
- **扫描确认**：先显示目录数量和扫描说明，“查看目录”分页展示完整路径。多个长路径不会把确认和取消按钮挤出屏幕。
- **输入表单**：搜索、模型编辑、历史重命名等输入在旋转时保留文字、光标和当前字段，并关闭旧的剪贴板弹窗。模型表单中间字段可滚动，操作区保持可见；长 Key 使用单行输入和内部滚动，不撑高窗口。实体键 Enter 可推进模型字段或确认搜索、重命名；取消保留原配置。

## 验证范围

测试使用隔离书籍副本和私有测试配置。聊天 HTTP/SSE 来自本地测试服务，本轮不使用真实 DeepSeek 凭据或额度。原始失败、修复和重验分目录保存。

本地最终验证已通过：23 组、199 个单元用例，63 个 Lua 文件静态检查（零警告、零错误），6 个 Python 工具语法检查，以及 18 个独立进程启动分支。启动覆盖经典界面、Anx 书架、最近文档、显式文件/目录、原生首页选项、恢复和禁用。

真实 SDL/X11 验证包括 360×640 中文大字灰度、480×800 英文彩色及旋转；书架/导入/设置/统计/笔记另外检查 640×220 短横屏。模型表单验证长测试 Key、输入及光标保留、剪贴板弹窗回收、实体 Enter、真实点击取消和聊天重启。EPUB 与 PDF 阅读入口和原生笔记/目录操作均有回归。原生模型表单在短横屏开键盘时滚动区较短，完整说明可通过滚动查看。

Android 11 / API30 / x86_64 已完成旧 `anxui9` 到 `anxui11` 的覆盖安装和运行验证，未清除应用数据。旧模型配置与历史迁移、触摸输入发送、停止、剪贴板、横竖屏、系统返回、前后台及重启恢复通过。书架另外完成批量已读、状态筛选、移出书架保留文件、移除扫描目录保留书籍、继续阅读与重启后位置/书签核对。Android 的初始扫描由真实扫描后端导入测试书籍；手动文件选择器的勾选、确认和取消交互由 SDL 验证。完整命令、结果和安装包见[执行记录](execution-state.json)和[证据汇总](/data/koreader-anx-work/evidence/W50-global-polish/summary.json)。

W48 的旧模拟器及数据保留。本轮使用独立测试环境，旧包准备阶段出现一次“System UI isn't responding”，核对系统弹窗后选择 Wait 才继续。此后升级及交互通过，但不构成无人工干预启动通过，也不证明旧环境故障或所有启动 ANR 已修复，见[干预记录](/data/koreader-anx-work/evidence/W50-global-polish/android-systemui-intervention.json)。测试完成后已停止本轮模拟器。ARM64 实机、墨水屏、系统中文输入法和其他服务需要各自实测，模拟器结果不替代这些结论。
